About the project

“Korean from Zero to the Grave”

A three-week, pure-frontend course project by six second-year CS students.

재미있게 배우는 한국어

Background

Why K-dramas and Korean?

Duolingo reports over 7.9 million active learners of Korean, and when Squid Game aired, new Korean learners in the UK jumped by 76%. Millions of people are drawn to Korean through dramas — but few tools connect immersive drama content with systematic micro-learning.

Our team of six are all drama fans. This project is both a course assignment and our first real team collaboration, so we chose a topic we genuinely care about.

Technology

Plain and open, on purpose

V1.0 is fully static: no frameworks, no backend, no database. Everything runs in the browser.

HTML5

HTML5 semantic markup, valid and readable

CSS3

CSS3 with Flexbox & Grid, external stylesheets

JavaScript

Vanilla JavaScript (ES6), no build tools

data.js

All lines and quizzes hard-coded in /js/data.js

localStorage

localStorage for XP, level, streak and completed lessons

Browsers

Chrome 90+, Edge 90+, Firefox 88+, Safari 14+

Constraints

What we worked within

No backend

Only HTML + CSS + JS basics — so we chose a static architecture.

Three weeks

About 40 hours per person, overlapping with classes.

Copyright

No real video streams — only text lines and our own generated illustrations.

Timeline

15 days from idea to V1.0

  1. W1

    Week 1 · Design & structure — wireframes, data model, three HTML skeletons, global CSS.

  2. W2

    Week 2 · Core features — learning flow, quiz logic, progress storage, responsive layout.

  3. W3

    Week 3 · Integration & delivery — full flow testing, cross-browser checks, docs and demo.
