Our story

Why we built this

We are all K-drama fans, and we noticed that most Korean-learning tools are either too textbook-like or too scattered. This project fuses systematic micro-learning with the immersive drama content we love.

Built from scratch in three weeks with plain HTML, CSS and JavaScript — no frameworks, no servers, no excuses.

화이팅! — “Team, let’s go!”

Division of work

Everyone owns a module

All code is reviewed by at least one other member before merging.

Project manager & CIO

Schedule control, tech choices, core logic, Git branch management and merging.

Site structure

Writes all HTML skeletons with semantic tags, coordinates class names with the CSS member.

Visual design & CSS

Korean pink/blue & black-white theme, font scale, all stylesheets, responsive media queries.

JavaScript & storage

Wraps localStorage read/write (getProgress / saveProgress), syncs completion state, recovers the current step after refresh.

Testing & docs

Writes test-case lists, tests on Chrome/Firefox/Edge, writes README and demo materials.

K-Drama Korean

Learn real Korean through the lines of your favourite K-dramas. Four short steps per lesson, points and streaks to keep you going.
